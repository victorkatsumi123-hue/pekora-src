# Pekora Source (Codespace Ready)

Repositório criado para rodar o código aberto do Pekora (Project X) no GitHub Codespaces.

## Como usar

1. Abra este repositório no GitHub: https://github.com/victorkatsumi123-hue/pekora-src
2. Clique em **Code** → **Codespaces** → **Create codespace on main**
3. Espere o ambiente carregar (pode demorar um pouco)
4. Depois me avise que o Codespace abriu que eu te passo os comandos pra clonar o source e configurar

Fonte original vazada: https://github.com/Anontux/pekora-latest-src

**Atenção:** Use por sua conta e risco. Revivals de Roblox podem violar ToS da Roblox.
